WorkOS Migration — Launch Plan

Draft for review · August 18, 2026 · Owner: Jessica Manner

Launch blocker: an issue affecting email edits during onboarding testing needs to be resolved before the mid-September release. Fix is in progress.
Overview

We're migrating login and account-info management to WorkOS AuthKit. Applicants, residents, and vendors will be able to sign up and log in with a Google or Microsoft account (Social Login) or a one-time emailed code (Magic Auth) instead of an Ender password. Internally, Ender/EG employees log in via their company identity provider (Enterprise SSO) — Ender via Google, EG via their Microsoft/Entra ID account. Once an account is tied to one of these, profile edits (starting with email) are managed through that identity provider rather than in-product.

QA Status

We identified 9 core login and onboarding flows that need to pass before launch. As of today: 1 passing, 5 failing with fixes in progress, and 3 pending final reconfirmation. We will not launch Phase 1 until all 9 are confirmed passing — that's the gate, not a target date.

We're also validating a full set of apply-flow scenarios (new vs. existing users, with and without token links) before this goes live.

Rollback Plan

Launch is gated behind a feature flag — if something goes wrong, we can flip it off immediately and public flows revert to the current login path with no disruption. We'd roll back if:

  • Any of the 9 core flows above is confirmed broken for any user — no threshold needed, login/auth issues are treated as launch-blocking by default.
  • Login or onboarding failures exceed roughly 5–10% over a sustained 15-minute window.
  • We see an abnormal spike in login-related support tickets relative to traffic.
